# Websites for classical musicians

A website and content services portfolio for classical musicians, ensembles, and festivals generated by the existing `tissue.py`, using Markdown, Jinja templates, and Tailwind CSS compiled through Node. All case studies are explicitly labeled self-directed concepts. The offer covers musician websites and press kits, ongoing updates, and season communications.

## Build

Requirements: Node 22 and Python 3 with venv support.

```bash
bash bash.sh
python3 -m http.server 8000 --directory public
```

Open http://localhost:8000. The build installs locked Node dependencies and Python dependencies in `.venv`, generates HTML through Tissue, and then compiles minified Tailwind CSS into `public/static/site.css`. Compiling after Tissue is deliberate: Tissue clears `public` at the start of each build.

## Cloudflare Pages

- Framework preset: None
- Build command: `bash bash.sh`
- Build output directory: `public`
- Root directory: this repository root
- Environment variable: `TISSUE_SITEMAP_BASE_URL=https://your-domain.example` (replace with your actual canonical domain)

When a canonical domain is not configured, the build uses Cloudflare's `CF_PAGES_URL`. Cloudflare builds reject a localhost sitemap. No Python or Node server is needed in production.

Cloudflare may install dependencies before the custom build; `npm ci` in the script intentionally makes the build independently repeatable. Commit `package-lock.json`.

## Make it yours

Edit `markdown/index.md` for your introduction. Edit `markdown/work/*.md` for case studies; replace samples with real work and verified outcomes when available. Navigation, hero, and other homepage sections live in `templates/template_home.html`; the name appears in `templates/base.html`. Add a real contact method and resume once you are ready to publish those details. Do not claim sample projects as client work.

Design tokens and styles live in `styles/input.css`. Tailwind scans templates, Markdown, and Tissue's section class mappings. The editing demo uses a small local script; all project links work without JavaScript.

Documentation: [Tailwind CLI](https://tailwindcss.com/docs/installation/tailwind-cli), [Cloudflare build configuration](https://developers.cloudflare.com/pages/configuration/build-configuration/).
